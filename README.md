## 🧠 Overview

FuelGuard AI is an AI-powered crisis management platform that transforms traditional reactive fuel monitoring systems into predictive, real-time, and intelligent decision-making systems.

It helps citizens, authorities, and fuel operators manage fuel shortages efficiently during crises such as geopolitical disruptions (e.g., Iran–Israel conflict).

---

## 🛑 Problem Statement

Fuel crises lead to:

- ⛽ Long queues and fuel shortages  
- 📈 Sudden price spikes  
- 😰 Panic buying and hoarding  
- 🗺️ Lack of real-time local data  
- ❌ Inefficient distribution  

Existing systems are reactive and data-only, lacking prediction and actionability.

---

## 💡 Solution

FuelGuard AI provides:

- 🔮 AI-based fuel shortage prediction  
- 🗺️ Real-time hyperlocal fuel tracking  
- 🚛 Smart distribution suggestions  
- 📢 Instant alerts (App + WhatsApp)  
- 🎫 Smart fuel credit system  
- ⚠️ Hoarding detection  

👉 Combines AI + real-time data + logistics optimization.

---

## ⚙️ Tech Stack

- Frontend: Next.js (React), Tailwind CSS  
- Backend: Node.js (API Routes)  
- Database: MySQL + Prisma ORM  
- AI Integration: Google Gemini AI  
- Maps: OpenStreetMap / Leaflet  
- Notifications: Firebase / SMS APIs  
- Bot Integration: WhatsApp API

## 🧠 How It Works

1. User accesses platform (Web / WhatsApp)  
2. AI predicts shortages  
3. System updates live map  
4. Users book fuel using credits  
5. Authorities optimize distribution  
6. Alerts notify users
